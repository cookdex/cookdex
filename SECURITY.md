# Security

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting form](https://github.com/cookdex/cookdex/security/advisories/new), or choose **Security → Report a vulnerability** in this repository. Do not include sensitive details in a public issue.

Include the app version, affected platform, and steps to reproduce using made-up recipes. Never send API keys, signing material, or personal recipe backups. Use the latest release when checking whether an issue is still present.
