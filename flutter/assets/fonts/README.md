# Amount display font

Unmodified Noto Sans Medium supplies all 18 single-character vulgar fractions
used by the read-only amount renderer. Normal app and editable text retain their
existing fonts. The font is bundled for offline, consistent Android/Windows glyph
coverage; no runtime font download occurs.
